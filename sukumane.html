スクマネ編：出店ページの作り方🌷

出店ページの作り方は、ここを見れば大丈夫です。
困ったらまずこのページを👉 上から順番に進めば、登録から提出までできます。
動画は5分ずつに分けてありますので、わからないところだけご覧ください。

0. はじめに：スクマネの仕組み（全体像）

流れ

  1. お客様が注文します（マルシェのホームページや出店ページの申込みリンクから）
  2. お客様に自動で受付完了メールが届きます（Zoomリンク付き）。出店者にも同じ内容がCCメールで届きます
  3. 開催前日の朝9時に、お客様へZoomリンク付きのリマインドメールが自動で届きます
  4. 売上と名簿はシステムの中で確認・印刷できます

売上金の振込スケジュール

  • 1日〜15日のお申し込み → 当月末日に振り込まれます
  • 16日〜月末のお申し込み → 翌月15日に振り込まれます
  • 売上金額が1,000円以上になると自動で振り込まれます

手数料

  • システム利用料：0円（出店料に含まれています）
  • カード決済手数料：3.3%（自動で差し引かれます）
  • 振込手数料：250円（振込時に差し引かれます）
つまずきポイント：振込は「申し込まれた日」で決まります。開催日ではありませんので、気をつけてください。

1. アカウント登録のしかた（はじめての人だけ）

※以前のマルシェで登録済みの人は、この手順は不要です。

  1. 専用フォームから利用申請をします
  2. 出店者情報を入力します
  3. 振込先の口座を入力します
  4. 規約を確認して送信します
  5. 運営から届くメールで、アカウントのIDとパスワードを確認します
つまずきポイント：IDとパスワードのメールが届かないときは、迷惑メールフォルダも確認してみてください。IDは「marche-〜」の形のものです。

2. 出店内容の基本設定

▶ 動画：登録相談会・前半（スクマネ基本設定・約25分）を見る

① 準備とログイン（00:03〜05:05）

  1. スクマネのIDとパスワードを用意します（マルシェ用に配布されたもの）
  2. Canvaで作ったお知らせ用画像を用意します（標準6枚、JPG形式で保存）
  3. イベントの日程、金額のメモを用意します
  4. オンラインの場合はZoomリンク、リアル開催の場合は会場の住所を用意します
  5. 配布されたIDとパスワードを入力してログインします

② イベントの新規登録と基本情報（05:05〜08:39）

  1. トップ画面から下部へ移動し、「講座・イベント日程」を選択します
  2. カレンダー画面が出たら、青色の「新規登録」ボタンを押します
  3. 「限定公開」のチェックボックスにチェックを入れます
  4. 必須項目のプルダウンから「オンラインサロンマルシェ」を選びます
  5. 自分のイベントタイトルを打ち込みます
つまずきポイント：「限定公開」のチェックを忘れないでください。

③ お知らせ画像の入れ方（08:39〜14:03）

  1. 「詳細」欄にある写真ボタン（画像の挿入）から、Canvaで作った6枚の画像を順番に取り込みます
  2. 挿入した画像が小さい場合は、横幅いっぱいになるまで下部をつまんで引き伸ばします
  3. 6枚すべて同じ大きさに調整します
つまずきポイント：画像は最初小さく入ります。引き伸ばして横幅いっぱいにするのがコツです。

④ Zoomリンクと日程の設定（14:03〜18:24）

  1. 画像から数えて3番目の「個別連絡事項・申し込み」欄にZoomリンク（またはリアル会場の情報）を入力します
  2. 開催する日付と時間を選択します
  3. 「手動で設定」にチェックを入れ、案内用のお申し込み内容（Zoomリンク等）を再度入力します
  4. 2回以上開催する場合は「追加」ボタンを押し、同様に日程とリンクを設定します
つまずきポイント：「個別連絡事項」に入れた内容は、お客様のお申し込み完了時に届く返信メールに載ります。大事な欄です。

⑤ お申し込みボタン（商品）の設定（18:24〜23:10）

  1. 複数参加などでない場合は、商品タイプはラジオボタンのままでOKです
  2. 商品名に、お客様が分かりやすいように日程や時間を入れます（例：11日19時など）
  3. 金額（無料なら0円、有料なら金額を入力）や定員を設定します
  4. 商品の「開始日」にオープン日（公開日）を指定し、日程とリンクを正しく紐付けます
  5. すべて入力が終わったら、一番下の「保存」ボタンを押します
つまずきポイント：商品の「開始日」はオープン日（公開日）にしてください。公開日より前ですと申し込めません。

⑥ 修正と提出用URLのコピー（23:10〜終）

  1. 修正するときは、作成したイベントの「紹介」画面、または管理画面の「編集」から内容を修正し、再保存します
  2. 管理画面の「講座・イベントへ紹介」の下にある「URLコピー」ボタンを押して、イベントページのURLをコピーします
  3. コピーしたURLを提出用のGoogleフォームに貼り付けます
つまずきポイント：いつでも「編集」から直して再保存できます。間違えても大丈夫です。

3. 別日・アーカイブありの設定

  1. 追加日程を作ります（別日程の追加方法は「2. 出店内容の基本設定」の④と同じ操作です）
  2. アーカイブ用の商品の組み立て方を確認します（具体例はCanva版マニュアルをご覧ください）
  3. 公開前のチェックリストを確認します

5. つまずきFAQ（質問会の4パート）

▶ 動画：登録相談会・後半（質問会）を見る

パート1：申請からID・パスワード受取まで

  • 専用フォームから申請後、数日で運営から登録用のIDとパスワードがメールで届きます。
  • メールが届かない場合は、迷惑メールフォルダも確認してみてください。

パート2：基本情報の入力と期限

  • 運営から送付されたマニュアルやひな形（テンプレート）に沿って入力します。
  • 提出期限を守ってください。期限に遅れると、オープン日の掲載が遅れて販促時間が短くなってしまいます。

パート3：サムネイル画像・バナー画像

  • 画像はギリギリまで大きく引き伸ばして見栄えよく整えます。
  • デフォルトで入っている仮のイベント名は消して、自分のイベント名や内容に書き換えてください。

パート4：カレンダーとZoom URL

  • マイページの「カレンダー」から「新規作成」を選び、開催日時ごとにイベントを立てます。
  • 「個別連絡事項」の欄にZoom URLを必ず入れてください。前日の朝9時のリマインドメールに、この内容が呼び出されて送られます。
